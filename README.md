# Sooriya Rice Mill – Rice Pre-Order Website

## Technologies
HTML, CSS, JavaScript, PHP, MySQL and Bootstrap-style responsive design principles.

## XAMPP Setup
1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the `sooriya_rice_mill` folder into `C:/xampp/htdocs/`.
4. Open `http://localhost/phpmyadmin`.
5. Create/import the database by selecting and running `database.sql`.
6. Visit `http://localhost/sooriya_rice_mill/`.

## Main features
- Responsive Home page
- Rice product cards
- Register and Login with `password_hash()` and `password_verify()`
- Session-based user dashboard
- Rice pre-order form
- Contact form
- MySQL database integration
- JavaScript form validation and smooth scrolling
